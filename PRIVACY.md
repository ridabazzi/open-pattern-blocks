# Privacy

Open Pattern Blocks is made for children, so it collects as little as possible.

The app, as published in this repository:

- has no accounts or sign-in
- does not ask for names, email addresses or ages
- has no ads, analytics, cookies or tracking
- does not save anything on a server
- does not load fonts, scripts or images from other services

Puzzle codes contain block shapes and positions only.

A website that hosts this app, such as GitHub Pages, may keep ordinary server logs.
Schools that need to know how logs are handled should check with their host, or run the
app from a local file.

Any change to this policy will be recorded in this file and reviewed in public.
