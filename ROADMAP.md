# Roadmap

Priorities will follow what teachers ask for.

## Now: the classroom basics

- [x] Six standard blocks with exact geometry
- [x] Puzzle play with touch, mouse and keyboard
- [x] Free build
- [x] Real-size PDF class sheets with answers
- [x] Shareable puzzle codes

## Next: better play

- [ ] Themed puzzles, such as animals, seasons and vehicles
- [ ] Sound and spoken instructions for children who cannot read yet
- [ ] Arabic, French and Spanish, with right-to-left layouts
- [ ] Larger touch targets for young children
- [ ] Install as an offline app

## Then: learning goals

- [ ] Fractions: which blocks make one whole hexagon?
- [ ] Symmetry: finish the other half of a design
- [ ] Skills by grade, matched to common standards
- [ ] Tangrams and other manipulatives

## Later: for whole classes

- [ ] Saved sets of class sheets, kept on the teacher's device
- [ ] Teacher-made puzzle collections to share with other teachers
- [ ] An optional class mode

Any feature that stores data about children needs a privacy and legal review first. The
core app stays free and works without accounts.
