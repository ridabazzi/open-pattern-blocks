# Contributing

Thanks for helping. You do not need to write code to contribute.

## Ways to help

- **Teachers:** try the app with a class and open a Classroom feedback issue. Please do
  not post children's names, photos or personal details.
- **Print checks:** print a sheet at 100% and check it against real blocks.
- **Translators:** help us prepare Arabic, French and Spanish.
- **Developers:** pick an item from [the roadmap](ROADMAP.md).

## Set up

```sh
npm install
npm test
npm run typecheck
npm run build
```

## Pull requests

1. Keep each pull request to one change.
2. Add a test for any behaviour you change in `src/core`.
3. Try play-screen changes with touch.
4. Do not add runtime dependencies without discussing it in an issue first.
5. Do not add accounts, tracking or third-party requests. See [PRIVACY.md](PRIVACY.md).

Pull requests need passing CI and a maintainer review before merge.
